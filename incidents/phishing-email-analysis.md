# Phishing Email Analysis

## Incident Summary

A suspicious email was identified attempting to impersonate a financial institution in order to steal user credentials.

## Indicators of Compromise (IOCs)

- Suspicious sender domain
- Malicious embedded link
- Urgent social engineering language
- Fake login page

## Investigation Steps

1. Reviewed email headers
2. Extracted embedded URLs
3. Checked domain reputation
4. Verified phishing indicators
5. Blocked malicious indicators

## Mitigation Actions

- Blocked sender domain
- Reported phishing attempt
- Updated email filters
- Alerted users

## Lessons Learned

Users should verify sender legitimacy and avoid clicking suspicious links.
