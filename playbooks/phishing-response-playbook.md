# Phishing Incident Response Playbook

## Objective

Provide a standardized process for handling phishing incidents in a SOC environment.

---

## Identification

- Analyze suspicious email headers
- Verify sender reputation
- Check embedded links and attachments
- Identify spoofed domains

---

## Containment

- Block malicious domains
- Quarantine affected emails
- Disable compromised accounts
- Isolate infected endpoints

---

## Eradication

- Remove malicious files
- Reset compromised credentials
- Remove persistence mechanisms

---

## Recovery

- Restore affected systems
- Monitor for reinfection
- Re-enable user access

---

## Lessons Learned

- Document incident timeline
- Improve email filtering
- Conduct user awareness training
